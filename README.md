 🎬 Netflix Data Analytics
 
 📌 Project Overview

This is an end-to-end **Netflix Data Analytics and Business Intelligence project** developed using **Python, SQL, Excel, and Power BI**. The project focuses on **data cleaning, data transformation, exploratory data analysis (EDA), SQL-based data analysis, KPI development, and interactive dashboard visualization** to generate actionable business insights from Netflix data.

The analysis evaluates **content performance, customer demographics, viewing behavior, ratings, genres, subscription patterns, and engagement trends** to support data-driven business decision-making.

 🛠️ Tools & Technologies

* **Python** – Data Cleaning, Data Preprocessing & Exploratory Data Analysis
* **Pandas** – Data Manipulation & Transformation
* **SQL / MySQL** – Data Extraction, Filtering, Aggregation & Analytical Queries
* **Excel** – Data Preparation & Initial Analysis
* **Power BI** – Data Visualization, KPI Development & Interactive Dashboarding
* **DAX** – Calculated Measures & Business Metrics
* **GitHub** – Version Control & Project Documentation

 📊 Key Business Analysis

* Analyzed **Movies vs TV Shows** distribution and performance
* Identified **Top 10 content based on watch time**
* Analyzed **genre popularity across countries**
* Evaluated **ratings distribution and content quality**
* Compared **subscription types and market share**
* Analyzed **customer retention and engagement trends**
* Segmented customers based on **age groups**
* Compared **high-rated vs low-rated content**
* Evaluated **director and cast influence on content performance**
* Identified **content consumption and engagement patterns**

 📈 Power BI Dashboard

The interactive Power BI dashboard provides:

* **Executive KPI Dashboard**
* Content Performance Analysis
* Customer Demographic Analysis
* Subscription & Retention Analysis
* Ratings & Genre Analysis
* Watch Time & Engagement Trends
* Country-wise Content Analysis
* Interactive **Slicers, Filters and Drill-downs**

 🔍 Data Analytics Workflow

**Raw Data → Data Cleaning → Data Transformation → Exploratory Data Analysis → SQL Analysis → Data Modeling → DAX Measures → Power BI Visualization → Business Insights**

 🎯 Project Objective

The primary objective of this project is to transform raw Netflix data into **meaningful, actionable business insights** using data analytics and business intelligence techniques.

The insights generated from the analysis can help stakeholders understand **customer preferences, content performance, subscription behavior, engagement trends, and market patterns**, enabling more effective **content strategy, customer engagement, and data-driven decision-making**.

## 💡 Key Skills Demonstrated

**Data Cleaning | Data Preprocessing | Exploratory Data Analysis | Data Transformation | SQL | MySQL | Python | Pandas | Data Visualization | Power BI | DAX | KPI Analysis | Customer Segmentation | Business Intelligence | Dashboard Development | Data-Driven Decision Making**
